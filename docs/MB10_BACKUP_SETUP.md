# الكمبيوتر الاحتياطي لجلب MB10 — دوام الميسر (النسخة التجريبية 0.2.23)

## الوضع الحالي
- الكمبيوتر الأساسي: `192.168.0.8`، هوية `primary`.
- الكمبيوتر الاحتياطي: `192.168.0.19`، حساب Windows: `excmanager`، هوية `backup`.
- جهاز MB10: `192.168.0.121:4370`. يعمل البرنامج داخل شبكة المكتب فقط، ويُرسل عبر HTTPS إلى `https://dawam-muyassar-stage.pages.dev`.
- قراءة 281 حركة من الكمبيوتر الاحتياطي بتاريخ 1 نوفمبر 2026 كانت **قراءة اختبار فقط**؛ لم تُرفَع.
- الكمبيوتر الأساسي يواصل العمل بالمفتاح القديم `MB10_IMPORT_TOKEN`. يفضّل تحديث ملفه Python لاحقًا إلى `0.2.23` ليبلغ الخادم عن حالة اتصال MB10 بصورة دقيقة.

## أول تشغيل على الكمبيوتر الاحتياطي — مرتان فقط
1. افتح Windows بحساب `excmanager`، وتحقق من وجود Python و`pyzk` (مكتملان وفق اختبار المستخدم؛ لا تعِد تثبيتهما).
2. نزّل **النسخة الأحدث** من ملف Python وأداة التثبيت الاحتياطي إلى Downloads، مرة واحدة فقط:

```powershell
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/SalehAliAbuBaker/dawam-almuyassar/feature/dawam-0.2.0-foundation/tools/mb10_sync.py" -OutFile "$HOME\Downloads\mb10_sync.py"
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/SalehAliAbuBaker/dawam-almuyassar/feature/dawam-0.2.0-foundation/tools/install_mb10_backup.ps1" -OutFile "$HOME\Downloads\install_mb10_backup.ps1"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$HOME\Downloads\install_mb10_backup.ps1"
```

3. في التشغيل **الأول** فقط، يُنشأ مفتاح عشوائي مستقل وطويل ويُحفظ في `$HOME\MB10_BACKUP_TOKEN.dpapi` مشفرًا بهوية Windows الحالية؛ يُنسخ إلى الحافظة مرة واحدة. **لا ترسل المفتاح في الدردشة أو GitHub**.
4. في Cloudflare Pages لمشروع **`dawam-muyassar-stage` فقط**، أضف متغيرًا سريًا باسم `MB10_BACKUP_TOKEN` وبنفس القيمة المنسوخة، في بيئة النشر التي يستخدمها هذا المشروع، ثم **أعِد نشر فرعه التجريبي**. لا تغيّر `MB10_IMPORT_TOKEN` القائم ولا إعدادات الإنتاج.
5. امسح الحافظة بعد لصق السر. شغّل الأمر التالي **مرة ثانية** في Windows `excmanager`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$HOME\Downloads\install_mb10_backup.ps1"
```

6. تظهر رسالة `Installed and started: DawamMuyassar-MB10-Backup`. تظل مهمة Windows تعمل تلقائيًا عند تسجيل الدخول، وحتى أثناء قفل سطح المكتب. لا تحتاج فتح PowerShell يوميًا. **لا تعمل عندما يكون الكمبيوتر مطفأً أو في وضع السكون أو الحساب مسجل الخروج.**

## مراقبة حالة النسخ الاحتياطي واختبار الانتقال
- افتح صفحة `/mb10-sync.html` بحساب مدير مخوّل، وستعرض حالتي الأساسي والاحتياطي مع الزمن الأخير لكل منهما، واسم منفذ آخر جلب.
- إن كان الأساسي يعمل ويصل إلى MB10، يعرض الاحتياطي «في وضع الانتظار» ولا يقرأ البصمات. إذا غاب الأساسي لأكثر من 60 ثانية، وكانت شبكة الاحتياطي سليمة، يمكنه أخذ المهمة التالية.
- للفحص دون تعطيل الإنتاج: بعد التأكد من عدم وجود مهمة جلب جارية، أوقف مهمة الأساسي من Windows مؤقتًا `Stop-ScheduledTask -TaskName 'DawamMuyassar-MB10-AutoSync'`، وانتظر حالة «غير متصل» في التطبيق، ثم اضغط «جلب البصمة الآن». يجب أن يظهر المنفذ «الكمبيوتر الاحتياطي» ويكتمل الجلب. أعِد تشغيل مهمة الأساسي بعد الاختبار `Start-ScheduledTask -TaskName 'DawamMuyassar-MB10-AutoSync'`.
- لا تختبر بإطفاء جهاز MB10 أو فصل كبل الشبكة عنه؛ يجب أن يبقى متاحًا للكمبيوتر الثاني.
- تحقق محليًا من المهمة والسجل دون عرض المفتاح:

```powershell
Get-ScheduledTask -TaskName "DawamMuyassar-MB10-Backup" | Select-Object TaskName,State
Get-Content "$env:LOCALAPPDATA\DawamMuyassar\MB10Backup\backup-sync.log" -Tail 20
```

## الحماية وحدود التشغيل
- عند إنشاء مهمة يطبَّق شرط ذري يمنع وجود مهمتين معلقتين/جاريتين في نفس اللحظة. عند استلام المهمة يربط الخادم رقمها بالكمبيوتر المنفذ، ويجدد الوكيل نبض المهمة أثناء قراءتها.
- عند فشل الكمبيوتر أو الإنترنت، لا تحذف البصمات؛ يعاد جلبها كاملة في المحاولة التالية. الاستيراد يستخدم معرّف الجهاز المشترك `mb10-main`، وبصمة الحدث نفسها، وقيدًا فريدًا في D1 و`INSERT OR IGNORE`. القيم المتطابقة تمامًا عند نفس الثانية تُعد حدثًا واحدًا إذا لم يقدم جهاز MB10 رقم حدث فريدًا.
- لا تُعدل البصمة الخام أو بيانات الرواتب أو مستحقات العاملين. الجلب قراءة فقط؛ ليس هناك إرسال أوامر مسح إلى الجهاز.
- **التحوّل الآلي ليس ضمانًا مطلقًا عند انقطاع مزدوج في الشبكة أو تعليق طويل جدًا**؛ تنتهي المهمة المهجورة بعد مهلة، وقد تتداخل قراءتان استثنائيًا، لكن لا يُدخل الحدث نفسه مرتين في D1.
- Web Push وتنبيهات «دوامي وتنبيهاتي»: جرّب بحساب عامل مرتبط وسجّل اشتراك Chrome في الجوال، ثم نفّذ اختبار التنبيه من الصفحة. لا تفترض وصول Push إلا بعد تأكيد الجهاز؛ لا خصم آلي.
- كل التعديلات في `feature/dawam-0.2.0-foundation`، ولا توجد تغييرات على `main`.

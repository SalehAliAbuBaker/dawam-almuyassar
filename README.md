# دوام الميسر — نسخة تجريبية 0.1.2

معاينة عربية على GitHub Pages **دون خادم أو Cloudflare**. الأيقونة لهوية دوام الميسر، وشعار المؤسسة للواجهة الداخلية والطباعة.

## تحديث 0.1.2
- اعتماد خط **Tajawal (تجوال)** نفسه المستخدم في تطبيق عطايا، بأوزان 400 و500 و700، لجميع واجهات المعاينة مع المحافظة على ألوان ومكونات التطبيق.
- تحديث رقم الإصدار الظاهر إلى **0.1.2**.

## تحديث 0.1.1
- إضافة 12 عاملًا افتراضيًا بأسماء تحمل عبارة (تجريبي)، وأقسام ورواتب وحوافز وأجور مساء متنوعة. يظهرون تلقائيًا عند أول استخدام للمعاينة في متصفح لا يحتوي بيانات عاملين؛ ويمكن إضافتهم لاحقًا من زر «+ بيانات تجريبية» دون تغيير البيانات الموجودة.
- إضافة زر **واتساب الأخضر** بجوار الخروج وفي صفحة الدخول، وصفحة **المساعدة والتواصل** تتضمن واتساب والاتصال على ‎+967734915588.
- إظهار رقم الإصدار 0.1.1 في الواجهة وشاشة الدخول والمساعدة.

## مهم
- بيانات العاملين ورواتبهم **افتراضية بالكامل** وغير مأخوذة من ملفات المؤسسة.
- التخزين محلي داخل المتصفح (IndexedDB)؛ ليس هناك مزامنة بين الأجهزة أو مصادقة دخول آمنة.
- لا تُدخل بيانات عاملين حقيقية في هذه المعاينة المنشورة للعامة.
- حسابات الخصومات المالية الحقيقية غير مفعلة بانتظار التحقق من اللائحة.
- الربط بجهاز ZKTeco MB10 وقاعدة Cloudflare D1 مؤجل إلى مرحلة لاحقة.

## النشر
Settings → Pages → Deploy from a branch → main → /(root).

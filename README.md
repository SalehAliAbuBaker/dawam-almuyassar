# دوام الميسر — نسخة تجريبية 0.1.0

هذه معاينة عامة تعمل عبر GitHub Pages دون قاعدة بيانات أو خدمة خلفية. الصفحة الرئيسية `index.html` تحتوي على الواجهة والشعارات المدمجة.

- المعاينة مخصصة للتجربة فقط. لا تدخل بيانات عاملين حقيقية.
- التخزين داخل متصفحك فقط (IndexedDB)، ولا توجد مزامنة عبر الأجهزة.
- الدخول إلى المعاينة ليس مصادقة أمنية حقيقية.
- خصومات الرواتب غير مفعلة حتى اعتماد سياسة توافق اللائحة.
- ربط ZKTeco MB10 وCloudflare D1 مرحلة لاحقة.

الهوية: شعار دوام الميسر للأيقونة والواجهة، وشعار مؤسسة الرأفة للداخل والطباعة.

للنشر: Settings → Pages → Deploy from a branch → main → /(root).
